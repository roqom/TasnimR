HTML5 Basic Struture: Start with this HTML Boilerplate

April 25, 2026

We start our web development journey at the most fundamental level which is HTML. HTML gives structure to our website. By knowing HTML well, we not only know how to structure our website, but also know how to properly organize using semantics. 
		
        <!DOCTYPE html>
        <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>HTML5 Boilerplate</title>
            <link rel="stylesheet" href="style.css">
            <script src="index.html" defer></script>
        </head>
        <body>
        </body>
        </html>
